# The Agent-Native Enterprise

**A reference operating model for organizations built on three rules. An agent or a human can fill any role. Every process is built for agents first. A human can stop, adjust, and continue every flow.**

The Agent-Native Enterprise is an operating model for organizations that are built for AI agents first. It keeps humans in the places where judgment and accountability have no substitute.

A role is a contract, not a person. An agent, a human, or a plain program can fill the same seat, and each one can replace the others.

Every flow carries a handbrake. Any authorized human can pause the flow, examine what happened and why, inject a correction, and continue from that exact point.

Humans sit above the loop as a Board. The Board can be a hundred people or a single founder. It writes a constitution, and a pipeline compiles that constitution into machine-readable rules that the system checks before every action. Agents never author their own rules. A human who steps into a seat inherits the authority of the seat, never the authority of their title.

Four operating roles run the value chain: Direction, Orchestration, Execution, and Verification. Three system roles keep the machine honest. A Steward repairs. An Optimizer matches capability to task. An Auditor rates versions and can stop a dangerous one, but can never restart it — to un-pause is a human act.

Risk is graduated by blast radius. Reversible routine work runs fully autonomous. An irreversible outward-facing act requires a human. Autonomy is earned from evidence and ratified by humans. It is never self-granted.

The unit is a sovereign cell. A cell can be a whole company, or one team inside an enterprise. Cells federate through treaties between Boards. They never reach inside one another.

The model names what it cannot prevent: a corrupted Board, a compromised store, and prompt injection. It contains those risks rather than denies them.

In one line: humans hold the Offices and write the law, agents fill the Roles and do the work, and anything can be stopped, corrected by hand, and continued — under a law that binds everyone.
